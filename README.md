# Catalyst

Catalyst is a Claude skill for diagnosing and fixing Intercom Albert/Fin issues, improving knowledge grounding, refining routing/escalation logic, and validating support bot quality with real customer scenarios.

## Included files

- [commands/catalyst.md](commands/catalyst.md)
- [skills/catalyst/SKILL.md](skills/catalyst/SKILL.md)

## Purpose

Use Catalyst to investigate bad Albert/Fin responses, identify the root cause, apply the smallest safe fix, and validate the outcome with representative QA cases.
